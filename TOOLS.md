# Research capability notes

This file documents capabilities; it does not install or enable tools.

## Deployment status
Actual researcher model, installed OpenClaw version, tool allowlist, credentials, paid data access and network reachability are not verified by this package. Confirm them in the running agent before benchmarking.

## Capability discovery
Use the runtime's advertised tools and the installed release's supported configuration/help. Never infer access from a template or a model name. Keep any local capability inventory under untracked private notes; do not place tokens here.

- Search: discovers sources. Material claims require the source contents, not just snippets.
- Fetch/browser: retrieve originals with the available authorized tool. A blocked URL is not evidence of the document's contents.
- PDFs/spreadsheets: check actual headings, footnotes and extraction quality. Cross-check suspect OCR against the page or table.
- Calculator/code execution: use available deterministic tools for important calculations. Avoid installing libraries or executing downloaded code as a retrieval workaround.
- File tools: store private evidence/state only if available. If absent, include necessary sources and limitations in the report; do not claim records were saved.
- Messaging: use only when the task explicitly authorizes destination and the scheduler is not already delivering the answer.

## Source selection by assignment
Use relevant exchange/regulator filings, company investor-relations reports, central banks, statistical agencies, customs authorities, and original datasets. Trusted news adds context. There is no universal country or ticker list.

Primary-source authority does not remove the need to inspect reporting basis, revisions and limitations. Syndicated articles are not independent confirmations.

## Fallbacks and access limitations
Retry a transient failure once. Try an authorized original mirror, issuer copy, alternate official release, or credible secondary source. Attribute secondary sourcing explicitly. Respect authentication and subscription limits; do not claim proprietary Bloomberg or broker consensus access unless it is actually configured.

Quotes must include provider, currency, timestamp/timezone, and live/delayed status when known. If timing or delay is unknown, say so. Never describe cached values as current without a freshness check.

## Citations
Use the destination's native supported citation format. Otherwise use portable Markdown links near the claim plus a short source list. Include publisher and publication/report date when known. Do not generate arbitrary citation tokens or fake URLs.

Synthetic benchmarks use fixture IDs instead of public links. Cite those IDs and do not browse for the fictional entities.
